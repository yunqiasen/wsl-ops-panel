# Agent MCP 紧凑列表与客户端专属卸载设计

**日期**：2026-07-15
**项目**：WSL Ops Panel
**状态**：用户已确认

## 1. 问题

当前 MCP 行把每个设备/客户端观测渲染成完整徽章。一个 MCP 安装到多个客户端时会产生多行徽章，撑高卡片并挤压操作区。现有“从本地库删除”只删除面板里的逻辑定义，不会修改目标客户端配置；虽然适配器已有本地 remove 函数，但没有目标卸载 API、任务队列或 UI。

安装队列还维护了一份独立的客户端写入脚本。紧凑改版必须保持客户端格式差异，卸载不能用“未选中”隐式推断。

## 2. 目标

1. MCP 行在桌面端保持单行主信息，常规高度约 64–76px。
2. 同一设备的多个客户端合并显示，例如 `当前 WSL · 已装 3：Codex / Claude / Gemini`。
3. 每行提供明确的 `安装/更新`、`卸载`、`编辑`；`从本地库删除`保持独立语义。
4. 卸载使用设备 × 客户端矩阵，只允许选择最近观测为已安装的目标。
5. 每个客户端按自身格式精确删除指定 MCP，保留其他 MCP 和无关顶层配置。
6. 写入前备份，原子替换，格式校验，写入后回读确认指定 MCP 已消失。
7. 本地和在线 Linux/macOS SSH 节点可入队；Windows继续明确不支持。

## 3. UI

### 3.1 紧凑行

桌面结构：

```text
[选] MCP 名称 / ID | 当前 WSL · 已装 3：Codex / Claude / Gemini | 安装/更新 卸载 编辑 更多
```

- 状态按设备聚合，不重复设备名。
- 客户端名称保持文字可见，超过可用宽度时显示 `+N`，完整明细保留在 `title` 和展开详情中。
- 描述和 JSON 放在次行，默认折叠；没有描述时不占额外空间。
- `更多`使用原生 `details`，其中放置“从本地库删除”。
- 移动端允许分成主信息、状态、操作三行，但按钮尺寸一致且不横向溢出。

### 3.2 双模式目标矩阵

同一个 dialog 支持 `install` 与 `uninstall`：

- 安装：所有在线、受支持目标可选；确认文案为“确认安装”。
- 卸载：只有该批 MCP 在目标客户端中全部被真实观测为已安装时可选；确认文案为“确认卸载”。
- 卸载预览明确列出删除数量，不影响未选中的 MCP。
- 批量卸载若多个 MCP 在同一单元格只有部分已安装，则该单元格禁用并显示“并非全部已装”，避免部分删除。

## 4. 客户端适配器

| 客户端 | 配置位置 | 卸载策略 |
|---|---|---|
| Codex | `~/.codex/config.toml` | 删除指定 `mcp_servers.<id>` table，保留其他 TOML |
| Claude Code | `~/.claude.json` | 从 `mcpServers` 删除指定键，保留其他顶层字段 |
| Gemini CLI | `~/.gemini/settings.json` | 从 `mcpServers` 删除指定键，保留 settings 等字段 |
| OpenCode | `~/.config/opencode/opencode.json` | 从 `mcp` 删除指定键，保留 local/remote 原格式 |
| OpenClaw | `~/.openclaw/openclaw.json` | 使用扫描发现的 MCP 表键并删除指定键 |
| Hermes | `~/.hermes/config.yaml` | 从 `mcp_servers` 删除指定键，保留 model 等字段 |

适配器和远程执行脚本共享同一组路径、表键和转换规则。卸载结果回读后，指定 ID 仍存在即失败。

## 5. API 与数据流

```http
POST /api/agent/mcp/uninstall
{
  "assignments": [
    {"node_id": "__local__", "client_id": "codex", "mcp_ids": ["context7"]}
  ]
}
```

API：

1. 校验客户端、节点、在线状态和平台。
2. 校验 observations，未观测为安装的目标进入 `skipped`，不入队。
3. 每设备合并为一个任务，每客户端生成独立卸载步骤。
4. 入队后只移除明确 MCP 的 desired assignment；其他分配不变。
5. 任务脚本备份、原子写入、解析、回读；失败由任务中心呈现。

本地库删除仍使用 `DELETE /api/agent/mcp/servers/{id}`，不触碰任何客户端配置。

## 6. 测试与验收

- 六个客户端适配器删除指定 MCP并保留其他配置。
- 删除不存在的 MCP不破坏文件，回读结果稳定。
- 卸载 API 支持本地/远程分组，跳过离线、Windows、未安装目标。
- 页面有独立卸载按钮和双模式矩阵，无语义混淆。
- 桌面 1600/1280 下状态聚合且卡片紧凑；390px 无横向溢出。
- 无控制台错误、失败请求和异常 HTTP。
